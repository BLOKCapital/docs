This section is for anyone writing code against BLOK Capital, whether that's a new facet, an integration, or an audit.

Start with [Quickstart](/en/builders/quickstart) to get the contracts building and testing locally. [Protocol Architecture V1](/en/builders/blok-capital-v1) covers how the pieces fit together, and the [per-facet reference](/en/builders/blok-c-v1-core/garden/facets/facet) shows exactly how something is implemented. For the deepest architectural detail, including a suggested reading order through the repository, see the [Smart Contracts](/en/smart-contracts) section.

The [Batched Rebalancer](/en/builders/rebalancer) covers how many Gardens get rebalanced together in one transaction. Before you write anything that touches funds, read [Security Considerations](/en/builders/security-considerations). If you're adding a new facet, follow the [facet creation guide](/en/builders/Guides/Facets) for folder structure, naming, and style. [DAO Governance](/en/builders/dao-governance/blokc-proposal) covers how protocol changes get proposed and approved.
