This section is for anyone writing code against BLOK Capital, whether that's a new facet, an integration, or an audit.

Start with [Quickstart](/en/builders/quickstart) to get the contracts building and testing locally. [Protocol Architecture V1](/en/builders/blok-capital-v1) covers how the pieces fit together, and [Blok-C-V1-Core](/en/builders/blok-c-v1-core) has the per-facet reference if you need to see exactly how something is implemented. For the deepest architectural detail, including a suggested reading order through the repository, see the [Smart Contracts](/en/smart-contracts) section.

Before you write anything that touches funds, read [Security Considerations](/en/builders/security-considerations). If you're adding a new facet, follow the [Guides](/en/builders/Guides) for folder structure, naming, and style. [DAO Governance](/en/builders/dao-governance) covers how protocol changes get proposed and approved.
